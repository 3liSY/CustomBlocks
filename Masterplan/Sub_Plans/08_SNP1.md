## Confirmed Bug (2026-06-03)

Snapshots revert to a wrong/different state after every server restart or player rejoin, regardless of which snapshot the developer manually selects. The system appears to load a snapshot on its own and ignores the user's selection.

**Symptom:** Select snapshot X → restart server or rejoin → world has reverted to a different snapshot, not X.

## Current System (what exists)

- Snapshot = full GZip JSON of ALL slots (`SlotManager.serializeSnapshotToJson`)
- Stored at `config/customblocks/snapshots/`
- Max 20 snapshots kept
- Auto-snapshot: every N minutes + on pre-op (bulk ops, hex update, etc.)
- Manual: `/cb snapshot` command
- GUI: `/cb snapshots` → `openSnapshotsGui`
- `/cb panic` = 2-step all-or-nothing rollback to most recent snapshot
- Restore is all-or-nothing (no per-block restore)
